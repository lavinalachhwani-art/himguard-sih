# HIMGUARD Logistics Command

**Smart India Hackathon (SIH) Submission**

### 📌 Project Overview
HIMGUARD Logistics Command is a Progressive Web Application (PWA) designed to optimize high-altitude logistics, supply chain routing, and resource management in extreme environmental conditions.
